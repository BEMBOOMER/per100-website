# PER100 by Upfront

De website van PER100: zie wat je eet. Statisch (HTML, CSS en een klein beetje JavaScript), zonder externe libraries.

- `index.html`: de homepage
- `privacy.html`, `voorwaarden.html`, `licenties.html`, `contact.html`, `pers.html`, `404.html`

De film is voorlopig een korte versie van 15 seconden.
